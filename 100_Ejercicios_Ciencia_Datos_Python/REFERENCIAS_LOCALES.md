# Material local revisado

[Volver al programa](README.md)

Antes de generar la colección se inventariaron y leyeron los 880 documentos de texto Markdown/TXT y los siete PDF existentes en las diez carpetas de ejercicios del repositorio. Se revisaron en detalle las referencias de Python, Pandas y Matplotlib, y los índices y criterios de las colecciones profesionales. Los archivos de datos preexistentes se identificaron como referencias; no se copiaron a los nuevos paquetes ni se presupuso su licencia para redistribución.

| Material | Uso en esta colección |
| --- | --- |
| [Aprende con Alf](../Ejercicios_aprendeconalf/) | Repaso de fundamentos, archivos, Pandas y visualización. Los ejercicios 401, 404 y 411 refuerzan recorridos; aquí se aplican a observaciones y validaciones. |
| [Pandas](../Ejercicios_aprendeconalf/11%20LIBRERIA%20PANDAS/) | Referencia para inspección tabular, selección, resumen y fechas. Se amplía la interpretación y se evita adoptar como regla universal eliminar faltantes. |
| [Matplotlib](../Ejercicios_aprendeconalf/12%20LIBRERIA%20MATPLOTLIB/) | Referencia para representaciones; en esta colección cada figura debe responder una pregunta. |
| [Lógica de programación](../Ejercicios_logica_programacion/) | Siete hojas PDF de operadores, condicionales, ciclos, procedimientos y funciones, leídas mediante extracción de texto. Se reutiliza la progresión conceptual, no sus enunciados matemáticos. |
| [Python profesional](../100_Ejercicios_Python_Profesional/README.md) | Nombres, contratos, comprobaciones, explicación y decisiones sin soluciones. |
| [Exercises_full_python](../Exercises_full_python/README.md) | Integración de fundamentos y contextos de operaciones y soporte. |
| [Ejercicios finales](../Ejercicios_finales_py/README_ejercicios.md) | Panorama de proyectos; los nuevos encargos se concentran en preguntas analíticas. |
| [Aplicaciones CLI](../100_Ejercicios_Aplicaciones_CLI_Python/README.md) | Reproducibilidad, configuración y separación de responsabilidades cuando aportan valor. |
| [Backend](../100_Ejercicios_Backend_Django_DRF_Monolito_Modular/README.md) | Referencia de entidades y persistencia; no se requiere construir APIs para analizar datos. |
| [Ciberseguridad](../100_Ejercicios_Python_Ciberseguridad/README.md) | Trazabilidad de evidencia y cuidado en las conclusiones. |

Las carpetas `Ejercicios_pensados_por_mi` y `Ejercicios_python_generados` no contenían documentos Markdown/TXT/PDF que aportaran una guía de ciencia de datos. Los scripts previos son trabajo del repositorio y permanecen sin cambios.

Esta colección se apoya en esos fundamentos, pero presenta preguntas, contratos y datasets sintéticos nuevos. El inventario no convierte recomendaciones antiguas en reglas: cualquier política de limpieza debe justificarse frente a su pregunta y población.

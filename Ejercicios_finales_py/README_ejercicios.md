## Eje Temático y Competencias
- **Modelo de Datos y POO**: Métodos mágicos (`__getitem__`, `__enter__`, `__call__`), inmutabilidad, metaclases y descriptores.
- **Tipado Estático Estricto**: `Protocol`, `TypeGuard`, `Generic[T]`, `@overload`, `TypedDict` y `Literal`.
- **Concurrencia y Asincronía**: `asyncio`, semáforos, queues, locks distribuidos, thread pools y multiprocessing.
- **Arquitectura de Software**: Repository Pattern, Unit of Work, Event Bus, Circuit Breaker y CQRS.
- **Ingeniería de Datos y Sistemas Distribuidos**: Streaming con backpressure, compresión, sharding, Raft consensus y Merkle Trees.
